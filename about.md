# Minixx's Orb Buffer
Par **Minixx**.

1. Ouvre le menu pause > **Orb Buffer**.
2. Mode **Record** : joue le niveau (la macro est sauvegardée à la fin / via Sauvegarder).
3. Mode **Assist** : quand tu cliques près d'une orbe, le mod teste plusieurs délais de clic, simule chaque trajectoire et garde celle qui colle le mieux à la macro.
